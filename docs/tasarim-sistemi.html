Qt'ye aktarım

Tüm stiller QSS ile uygulanabilir. Gölge ve bulanıklık kullanılmaz, paneller yüzey tonu ve 1px çizgiyle ayrılır. Mod, pencereye verilen mode özelliğiyle değişir.

/* tema.qss — token'lar Python tarafında yerine konur */
QMainWindow, QWidget {

  font-family: "Source Sans 3"; font-size: 14px;
}

  border-radius: 3px; min-height: 36px;

QLineEdit:focus { border-color: #F0B449; }

/* Profesyonel mod: setProperty("mode", "pro") */
[mode="pro"] QPushButton, [mode="pro"] QLineEdit {

Yap

  • Bir ekranda yalnızca bir amber düğme olsun.
  • Her ayarın iki etiketi olsun: Basit modda sonucu, Profesyonel modda teknik değeri.
  • Sayıları JetBrains Mono ile, alt alta hizalı yaz.
  • Profesyonel modda değerin hangi profilden geldiğini altına küçük yazıyla göster.
  • Uyarıları ikon ve cümleyle ver, yalnızca renkle değil.

Yapma

  • Video önizleme alanını griye boyama, nötr siyah kalsın.
  • Bricolage'ı tablo, liste ya da ayar etiketinde kullanma.
  • QGraphicsDropShadowEffect ile gölge ekleme.
  • Basit modda Mbps, VBV, GOP gibi terimleri gösterme.
